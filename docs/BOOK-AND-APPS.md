## 1. The book — this is `kray-node`

One writer. One journal. One atlas. One cascade root on Bitcoin.
Signature ‖ Merkle proof ‖ Bitcoin anchor, or it did not happen.

This is what follow / guardian / validate **is**:

| Act | What it is |
|---|---|
| **Donate** | Sacrifice: real sats burned → **₭** is born (1:1, proof-of-burn). |
| **Create** | With ₭, write **stars** into the **atlas** (bytes, hash-checked). A written star is a relic. |
| **Burn ₭ → Ӿ** | The fire already paid. Ӿ moves under THE FIREBORN LAW. |
| **Honor** | Proven work (validate, hold the library) → soulbound **Glow**. One star, one vote. |
| **Seal a paper** | A contract on a star you own. Anyone may hang another idea on the same book. |
| **Validate** | Replay the journal. Earn ₭ (fee pool, linear) + Glow. Fuel for your own project (A7). |

A clone that follows **never** needs pot keys, `owner.box`, the pen, or a
guardian signer. Protocol “vaults” in the journal are rebuilt on replay.
They are not the bakery pot secret.

Igniting the unique writer is lighting **this** book in the air. That is
the foundation. Not “turning DeFi on.”

## 2. The apps — first tenants, not the node

The same journal can carry **application** events. They still pay 1 ₭ (A2).
They still fold into the **same** root (A8). They are **not** what “run a
node” means.

The first applications (built here to prove the door, like a company that
ships a product on KRAY.NETWORK):

| Application | What it is | What it is not |
|---|---|---|
| **Rune L2 / pot bridge** | Peg L1 runes through a shared bakery pot. Deposit is SPV. Exit needs a Bitcoin signature. | The ledger. The reason to clone `kray-node`. |
| **Pen + owner box** | Loopback signer for **pot payouts**. Phrase in the head. Reverse tunnel so the writer sees localhost. | A second writer. Part of follow. |
| **Guardian federation (2-of-3)** | Independent books that **gate a rune exit**. Fail-closed. | Required to donate, inscribe, move Ӿ, or earn Glow. |
| **DeFi (AMM and kin)** | Markets sealed as acts on the book. | A second network. The validator’s default job. |

Say it out loud to a stranger:

> You run the node to hold the book: sacrifice → ₭ → stars / Ӿ / Glow.
> Rune bridge and DeFi are apps on that book — the first ones. You can
> build the next one the same way.

KRILL, Radiola, Satspace, kray.space marketplace — same class: **tenants**.
Thousands more may hang papers. None of them rename the node.

## 3. Teach this in the quiz

When a human says “run a node”, teach **§ 1**. Do **not** ask for pot
vault keys. Do **not** install a pen. Do **not** start a writer.

If they say “I want to exit a rune / run the bakery / sign the pot”,
then — and only then — open [`POT-CUSTODY.md`](POT-CUSTODY.md). That is
application ops, not follow.
