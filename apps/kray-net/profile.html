Contracts

A contract here is an account with no key — only its own rules move it. The star page or the write studio LAW tab hangs a being or a form on a face (v2, burns 1 ₭) — raffle and mint live there (mint needs the face as parent of every child). This box seals a v1 pot (no star, no burn): a form (escrow / tunnel / vest / locked scroll) or raw IR. The language is total: no loops. A stamp, unlocked scroll, raffle, or mint needs a star.

Signing the code is signing its canonical hash — you cannot approve one program and deploy another.

A call costs the eternal fee and is signed over the contract, the rule and every argument — change one argument and the signature stops verifying. The reducer runs the rule itself and demands that the payments recorded in the journal are exactly the ones the code produces, or the node halts. Code is law here in the literal sense: nobody, including this node, can pay out what the rules did not say.
