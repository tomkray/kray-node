# BITCOIN

A peer-to-peer network needs a way to agree without a mint, a court, or
a company. Bitcoin solved that. Work is public. The chain with the most
work is the history. Anyone can verify. No one can rewrite a buried
block without redoing the work.

KRAY does not replace this.

The law of that invention lives **on this star**. Not as a person's
name in the skeleton. As the mooring. A later star may honor a
name. It does not outrank this clock, and it is not a thirteenth
neuron.

KRAY is a book that **moors** to it. Every byte of state that exists
here exists only if:

```
signature  ‖  Merkle proof  ‖  Bitcoin anchor
```

If a stranger cannot re-derive it from the bytes alone, it did not
happen. That sentence is the Supreme Law. It is Bitcoin's own security,
spent as a second book — not a second faith.

## What must remain true

1. **No trusted third party writes the leaf.** A writer is a door, not
   a mint. A model is a mouth, not a witness. A guardian serves
   liveness; it never decides truth.
2. **The clock is Bitcoin's.** Height, work, the pot, the burn. We do
   not invent time.
3. **Conservation or HALT.** Units are not stories. Σ balances equal
   emitted minus burned, or the node freezes.
4. **One chain.** Fail-safe, not fail-fork. A future-era event freezes
   an old node. There is always exactly one Bitcoin-anchored book.
5. **The address is the user.** A key that re-derives to itself. No
   account we hold for you.

## What this neuron forbids

A clever path that skips the proof. An admin key. A convenience that
moves state because someone asked nicely. A mouth that says “trust me,
I read the model.” Those are the third party. They are a hole.

The whitepaper taught a stranger they need not trust a mint. This star
is where that teaching sits in the mind — the mooring. Changing that
teaching is a different network. The glyph is **₿** — the mark already
belongs to the chain we moor to; there is no second Bitcoin.
