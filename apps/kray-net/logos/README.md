# Marks

Two glyphs. Two jobs. Do not mix them.

| Prefix | Glyph | Job | Door |
|---|---|---|---|
| `k-*` | ₭ | The node. Header, favicon, `/kray-mark.svg`. | KRAY.NETWORK |
| `x-*` | Ӿ | Nyx / Fenyx. Fireborn light. `/nyx-mark.svg`. | Rank, burn, profile — never the header |

Live chrome stays the **K**. The **X** is ready wherever Nyx is spoken.

## Use

- **SVG (preferred):** `/nyx-mark.svg` — disc. Inline: `<svg><use href="#g-nyx"/></svg>` (`currentColor`).
- **PNG kit:** same cuts as the K — source, white, black, disc, pad, tight, orientations, favicon sizes.
- **Do not** swap `/kray-mark.svg` or the header for the X. A second mark is a second story.

Source drawing of the X lives in `x-source.png` (1024², the Creator's stroke).
