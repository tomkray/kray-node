# THE LIBRARY MANIFEST — which pins seal as stars, and which never do

> Doctrine star: `later/38-library.md` (parent `whitepaper`).
> Rank of truths: **the journal is the fact · the code is the law ·
> the paper is dated intent.** A sealed pin is a birth certificate,
> never an amendment.
>
> Rite: each pin seals as a **content star, child of the `library`
> star**, in the birth order below (the story reads forward). Text
> may ride zipped at the desk's discretion (bytes frozen at seal).
> Sealing waits for the Creator's hand — this manifest is the plan,
> not the act.

## THE GATE (checked pin by pin, before every seal)

1. **Stone only** — the last edit is history: RATIFIED, EXECUTED,
   LOCKED, or HISTORICAL in its own status line.
2. **No secret, ever** — no host, no key, no live topology, no
   operator runbook. An inscription is an eternal leak with no
   refund.
3. **A snapshot, not a throne** — the star proves the paper existed;
   the reducer stays the only law. If code and paper disagree, the
   code wins and the paper remains a dated fact.
