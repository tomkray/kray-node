# LIVE MINT

**Parent:** `bridge`
**Action:** Prove a rune that is still being minted, from bytes
alone, so a live mint may bridge exactly like a premine.

A premine is easy to prove. Its whole supply is born at the etch, so
the ancestry walk of any deposit terminates cleanly at that one
Bitcoin transaction — every parent buried under weighed work, the
allocation law re-run link by link, down to the etch and no further.
That path worked, and it stays intact.

A rune with its mint OPEN is a harder truth. Coins keep being born
after the etch, in later blocks the etch does not name. The old walk
had nowhere to stop for such a coin — it asked for a global index it
must not trust, and answered `needs-index` / `mint-unproven`. So a
deposit of a live-minted rune hung, held, while every premine crossed
the bridge without a scratch. The problem was never the extension,
never a missing rite: it was an honest gap in what the bytes could
close. Two holes were closed the same night, both from bytes, neither
by a guess.

**The mint witness.** A mint OF THE FOCUSED RUNE may terminate the
walk when the entry carries the writer's mint witness — the block's
coinbase and a BIP-37 path proved against the SAME header, the very
mechanism that proves an etch's identity. Every byte-provable fact
stays byte-proven: the burial, the Mint tag, the BIP-34 height, the
window and the amount read from the etch's OWN terms in the same
bundle. Only cap-legality — global state no light verifier can decide
— is the writer's statement, journaled in the event so replay stays
deterministic (A3). A naked mint, a foreign coinbase, a shut window,
a bundle missing the etch — all still refuse. The law only WIDENS
what is accepted; every bundle valid before stays valid, so it was
born at 0 on signet and main without forking a single journal.

**The honest floor.** A proof also has to clear a minimum of real
Bitcoin work, or a cheap forged header could pretend a block was
buried. That floor had drifted to a recent-typical value that sat
ABOVE an honest historical block. The etch of `DOG•GO•TO•THE•MOON`
carried 13,408,187 of work — a real Signet block — and the too-high
floor refused it as unproven, making every live-mint deposit of that
rune impossible to prove. The floor was pinned to the work of Signet's
own powLimit: the easiest header Bitcoin Signet itself accepts. An
honest old block now clears it; a header easier than powLimit already
fails the proof-of-work check. A floor must never refuse an honest
etch.

## Stone

A premine terminates at its etch; a live mint could not — until the
mint witness let a coinbase-proven mint of the focused rune end the
walk, every other fact still byte-proven, cap-legality journaled for
deterministic replay. The work floor was pinned to powLimit so an
honest historical etch is never refused. The bridge does not care how
a rune was born; it cares only that the bytes prove it.
